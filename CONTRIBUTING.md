# Contributing to 18PlusAi Studios Enterprise

Thank you for your interest in contributing to our VR/AR enterprise platform! This document provides guidelines and instructions for contributing.

## Age Requirement

**IMPORTANT**: All contributors must be 18 years of age or older to participate in this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/VR-AR-enterprise.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes thoroughly
6. Commit your changes: `git commit -m "Add: brief description"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Submit a pull request

## Development Setup

### Prerequisites

- Node.js 18+ or Python 3.9+
- Unity 2021.3+ (for VR/AR development)
- Git
- Docker (optional, for containerized development)

### Installation

```bash
# Clone the repository
git clone https://github.com/goody81/VR-AR-enterprise.git
cd VR-AR-enterprise

# Install dependencies (if applicable)
npm install  # or pip install -r requirements.txt
```

## Coding Standards

- Follow the existing code style
- Write clear, descriptive commit messages
- Add comments for complex logic
- Include unit tests for new features
- Update documentation as needed

## Commit Message Guidelines

Format: `Type: Brief description`

Types:
- `Add:` New features or files
- `Fix:` Bug fixes
- `Update:` Changes to existing functionality
- `Docs:` Documentation changes
- `Refactor:` Code refactoring
- `Test:` Adding or updating tests
- `Chore:` Maintenance tasks

## Pull Request Process

1. Ensure all tests pass
2. Update the README.md with details of changes if applicable
3. Update documentation as needed
4. Request review from maintainers
5. Address any feedback
6. Await approval and merge

## Code Review

All submissions require review. We use GitHub pull requests for this purpose.

## Testing

- Write unit tests for new features
- Ensure all existing tests pass
- Add integration tests where appropriate
- Test VR/AR functionality on target devices

## Reporting Bugs

Use GitHub Issues to report bugs. Include:
- Clear description of the issue
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Unity version, device, etc.)
- Screenshots or videos if applicable

## Feature Requests

We welcome feature requests! Submit them via GitHub Issues with:
- Clear description of the feature
- Use case and benefits
- Any implementation ideas

## Questions?

Feel free to open an issue for questions or reach out to the maintainers.
