# UI Module

This directory contains user interface components and assets.

## Structure

- `components/` - Reusable UI components
- `pages/` - Page-level components
- `assets/` - Images, fonts, icons
- `styles/` - CSS/SCSS files

## Technologies

- React/Vue (planned)
- Three.js for 3D rendering
- WebXR for VR support
- AR.js for AR support

## Development

Components should be modular, reusable, and follow the project's coding standards.
