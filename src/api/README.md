# API Module

This directory contains API routes and controllers for the VR/AR Enterprise Platform.

## Structure

- `routes/` - API route definitions
- `controllers/` - Business logic controllers
- `middleware/` - Custom middleware functions
- `validators/` - Request validation logic

## Usage

API endpoints are organized by feature:
- `/api/vr` - VR-related endpoints
- `/api/ar` - AR-related endpoints
- `/api/users` - User management
- `/api/auth` - Authentication

See [API Documentation](../../docs/api/README.md) for details.
