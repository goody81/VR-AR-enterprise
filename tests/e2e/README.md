# End-to-End Tests

This directory contains end-to-end tests that verify the entire application flow.

## Running Tests

```bash
npm run test:e2e
```

## Test Coverage

- User registration and login
- VR device setup and sessions
- AR marker detection and tracking
- API interactions
- Age verification flow

## Tools

- Playwright (planned)
- Puppeteer (planned)

## Guidelines

- Test complete user journeys
- Use production-like environment
- Test across different browsers
- Verify UI interactions
